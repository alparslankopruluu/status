# AGENTS.md - Codex & Universal Agent Router

> **Universal Router for AI Agents (Codex, Grok, Gemini, Claude)**

## Project Overview
StatusOwl is a cross-platform (Mac & Windows) menu bar / system tray monitoring tool that displays AI assistant usage quotas (Grok, Antigravity, Claude Code, Codex) with an expressive animated Owl mascot.

## Rules & Safety Gates
1. Read `PRODUCT.md` before making UI or mascot design changes.
2. Check `docs/architecture.md` when modifying Rust-TS IPC or provider readers.
3. Verify that changes build cleanly using `npm run build`.
4. Keep git history clean with descriptive commit messages.
